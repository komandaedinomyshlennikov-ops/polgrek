Сайт уже отправляет события через JavaScript (reachGoal).
Без создания целей в кабинете события НЕ появятся в отчёте «Конверсии».

Покупка книги происходит на Литрес. Цель «litres» = клик «Купить»,
а не факт оплаты. Оплаты смотрите в Литрес / AdvCake.


--------------------------------------------------------------------------------
1. КАК ЗАЙТИ И СОЗДАТЬ ЦЕЛЬ (общий алгоритм для КАЖДОЙ цели)
--------------------------------------------------------------------------------

1) Откройте https://metrika.yandex.ru
2) Выберите счётчик: PolGrek — 110711984
3) Меню: Настройка → Цели
4) Кнопка: «Добавить цель»
5) Тип условия: «JavaScript-событие»
6) Поле «Идентификатор цели»:
   — скопируйте СТРОГО из колонки «ИДЕНТИФИКАТОР» ниже
   — латиница, без пробелов, без кавычек
   — регистр важен: litres ≠ Litres
7) Название цели: любое удобное на русском (для себя)
8) Условие: «совпадает» + тот же идентификатор
9) Ценность цели: по желанию (см. рекомендации у целей)
10) Сохранить

Повторите для каждой строки таблиц в разделах 2–4.


--------------------------------------------------------------------------------
2. ОБЯЗАТЕЛЬНЫЕ ЦЕЛИ (создать в первую очередь)
--------------------------------------------------------------------------------

Эти 5 целей — минимум для воронки продаж книг.

--------------------------------------------------------------------------------
ЦЕЛЬ 1
--------------------------------------------------------------------------------
Идентификатор:     litres
Название:          Литрес: клик «Купить»
Когда срабатывает: клик по кнопке/ссылке на litres.ru
                   (кнопки «Купить на Литрес», рейтинг-карточки, навигация)
Параметры:         book (slug книги), lang (ru|en), path
Ценность (опц.):   300–500 ₽ (оценка «намерения», не чек)
Зачем:             ГЛАВНАЯ конверсия сайта — намерение купить

--------------------------------------------------------------------------------
ЦЕЛЬ 2
--------------------------------------------------------------------------------
Идентификатор:     book_view
Название:          Книга: просмотр карточки
Когда срабатывает: открытие страницы книги
                   (/knigi/{slug}/ или legacy /books/...)
Параметры:         book, lang
Ценность (опц.):   0
Зачем:             спрос по названиям; знаменатель воронки

--------------------------------------------------------------------------------
ЦЕЛЬ 3
--------------------------------------------------------------------------------
Идентификатор:     excerpt_open
Название:          Отрывок: открыть на сайте
Когда срабатывает: клик «Отрывок» / «Читать отрывок»
                   (переход к #excerpt или страница отрывка)
Параметры:         book, lang, path
Ценность (опц.):   50 ₽
Зачем:             доверие до покупки — «сначала почитали»

--------------------------------------------------------------------------------
ЦЕЛЬ 4
--------------------------------------------------------------------------------
Идентификатор:     excerpt_download
Название:          Отрывок: скачать файл
Когда срабатывает: скачивание txt-отрывка
Параметры:         book, lang
Ценность (опц.):   50–100 ₽
Зачем:             сильный интерес; часто важнее, чем просто open

--------------------------------------------------------------------------------
ЦЕЛЬ 5
--------------------------------------------------------------------------------
Идентификатор:     book_quiz_complete
Название:          Квиз: рекомендация готова
Когда срабатывает: завершение блока «С какой книги начать» (3 шага)
Параметры:         book (рекомендованная), want, lang
Ценность (опц.):   0
Зачем:             работает ли подбор; какие книги советует

5. СОСТАВНЫЕ (МНОГОШАГОВЫЕ) ЦЕЛИ — ВОРОНКИ
--------------------------------------------------------------------------------

После создания одиночных целей:

Настройка → Цели → Добавить цель → тип «Составная цель»
(или «Многошаговая» — как названо в текущем интерфейсе Метрики).

--- Воронка A: «К осознанной покупке» ---
  Шаг 1: book_view
  Шаг 2: excerpt_open     (если нельзя «ИЛИ» — сделайте вторую
         воронку с excerpt_download вместо шага 2)
  Шаг 3: litres

Смысл: открыл книгу → посмотрел текст → кликнул «Купить».

--- Воронка B: «Квиз → покупка» ---
  Шаг 1: book_quiz_complete
  Шаг 2: litres

Смысл: окупается ли блок «С какой книги начать».

--- Воронка C: «Каталог → покупка» ---
  Шаг 1: filter_books   (или catalog_search)
  Шаг 2: book_view
  Шаг 3: litres

Смысл: поиск/фильтр приводит к покупке или нет.

7. ПРОВЕРКА, ЧТО ЦЕЛИ РАБОТАЮТ
--------------------------------------------------------------------------------

1) Откройте https://polgrek.site в режиме ИНКОГНИТО
2) Подождите 8–10 секунд после полной загрузки страницы
   (счётчик подключается с задержкой для скорости сайта)
3) Откройте любую книгу, например:
   https://polgrek.site/knigi/reset/
4) Через 5–15 минут в Метрике:
   — Онлайн / Конверсии → должна появиться book_view
5) Нажмите «Отрывок» → цель excerpt_open
6) Нажмите «Купить на Литрес» → цель litres
7) На главной пройдите квиз до конца → book_quiz_complete

Если цели не видны:
  • опечатка в идентификаторе (сверьте с этим файлом);
  • Adblock / блокировщик режет mc.yandex.ru — отключите на время теста;
  • цель создана как «Посещение страниц», а нужно «JavaScript-событие»;
  • ушли со страницы раньше 8–10 секунд после load.


--------------------------------------------------------------------------------
8. КАК ЧИТАТЬ ОТЧЁТЫ ДЛЯ ПРОДАЖ (раз в 7 дней)
--------------------------------------------------------------------------------

Период: 7 или 14 дней (не «сегодня»).

1) Отчёты → Конверсии
   • litres / визиты = конверсия в клик покупки
   • excerpt_open + excerpt_download / book_view = «читали до покупки»

2) Цель litres → срез / параметр book
   • топ книг по кликам «Купить»
   • эти книги усиливать на главной (hero, ситуации, квиз)

3) Воронка A
   • где самый большой % отвала — туда править тексты и кнопки

4) Сверка с партнёркой
   • litres в Метрике = клик
   • заказы = Литрес / AdvCake
   • раз в месяц: топ book в Метрике vs топ продаж в AdvCake
