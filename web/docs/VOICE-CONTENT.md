# Контент × Tone of Voice (Пол Грэк)

Источник: Threads DNA + редакционное правило бренда для РФ/СНГ.

## Читатель

Пишем не для западного middle-class, а для человека из России и СНГ 30–60 лет.

Он не говорит: «У меня cognitive overload».
Он говорит: «Голова вообще не варит.» «Проснулся — а уже устал.» «Не могу собраться.» «Память стала подводить.» «Телеграм открыл на две минуты, а прошло сорок.»

Это живой русский язык. На нём строится узнавание.

| Не писать | Лучше написать |
| --- | --- |
| Проверяете почту | Открываете Telegram |
| Календарь встреч | Список дел в заметках |
| Weekend recovery | Выходные пролетели, а не отдохнули |
| Hustle culture | Живу как на автопилоте |
| Burnout | Будто внутри постоянно включён режим тревоги |

## Кухонная наука

Нейробиолог сидит с читателем не в аудитории, а на кухне. Факты не упрощаются — убирается академический жаргон.

Плохо: «Хроническая гиперактивация оси HPA приводит к дисрегуляции кортизолового ответа.»

Пол Грэк: «Если мозг неделями живёт в ожидании угрозы, он начинает экономить энергию. Отсюда знакомое состояние: ничего катастрофического не произошло, а сил всё равно нет.»

## Три реакции на каждом экране

1. «Это про меня.» — бытовая ситуация из жизни РФ/СНГ.
2. «Теперь понятно, почему так происходит.» — короткое научное объяснение.
3. «Значит, это можно изменить.» — книга как инструмент, не товар.

Ни одного абзаца ради красивой фразы. Каждый абзац: «Меня поняли» или «Теперь я понял себя».

Главная: первый экран ~100vh. Книги — только после первого скролла.

## Аннотация книги (схема)

| Блок | Файл | UI |
|------|------|-----|
| Hook | `book-voice.ts` → `hook` | tagline / OG description / card blurb |
| Essence | `essence` | 2–3 предложения |
| Vibe | `vibe[3]` | маркеры |
| CTA line | `ctaLine` | под кнопками |

Кнопки (глобально `BUY_VOICE`):

- primary: **Читать фрагмент бесплатно**
- secondary: **Забрать на Литрес**
- optional: **Читать на Amazon**

## Не делать

- «Приобрести электронную версию»
- «Подписывайтесь, чтобы следить за выходом»
- «Станьте лучшей версией себя»
- FOMO / таймеры / «последний шанс»
- Западные ритуалы утра (inbox, calendar, weekend recovery, hustle)
- Диагноз вместо узнавания («симптомы», «тест личности»)
