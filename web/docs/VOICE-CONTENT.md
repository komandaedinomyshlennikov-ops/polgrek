# Контент × Tone of Voice (Пол Грэк)

Источник: Threads DNA + стратегия оптимизации под `polgrek.site`.

## Столпы голоса

1. **Интеллектуальная провокация** — reframe / парадокс в первой строке  
2. **Лаконичность** — короткие предложения, ноль «эта книга рассказывает»  
3. **Диалог на равных** — эксперт без пьедестала  
4. **Тёмный/философский подтекст** — атмосфера, не инфоцыганство  

## Аннотация книги (схема)

| Блок | Файл | UI |
|------|------|-----|
| Hook | `book-voice.ts` → `hook` | tagline / OG description / card blurb |
| Essence | `essence` | 2–3 предложения |
| Vibe | `vibe[3]` | маркеры ⚡🧬🔥 |
| CTA line | `ctaLine` | под кнопками |

Кнопки (глобально `BUY_VOICE`):

- primary: **Читать фрагмент бесплатно**  
- secondary: **Забрать на Литрес**  
- optional: **Читать на Amazon**

## Соцблок

`SOCIAL_VOICE`: «Закулисье без фильтров» + Threads / Telegram.

## Не делать

- «Приобрести электронную версию»  
- «Подписывайтесь, чтобы следить за выходом»  
- «Станьте лучшей версией себя»  
- FOMO / таймеры / «последний шанс»
