Счётчик: **110711984** · домен: **polgrek.site**

Код на сайте уже шлёт `ym(id, 'reachGoal', name, params)`.  
В кабинете нужно **создать цели** с теми же идентификаторами — иначе события уходят «в пустоту» и в отчётах «Конверсии» пусто.

---

## Зачем цели (логика продаж)

Сайт не продаёт «в корзине» — покупка на **Литрес**. Метрика ловит **намерение купить** и шаги до него.

```
Визит → интерес (книга / квиз / каталог)
      → доверие (отрывок)
      → клик «Купить на Литрес»  ← главная конверсия сайта
      → (опц.) почта / Telegram   ← повторные продажи
```

**Качество продаж** = не «как можно больше кликов», а:

1. С какой **книги** кликают (`book`).
2. Доходят ли до **отрывка** до покупки (или кликают вслепую).
3. Где **отвал**: home → карточка → отрывок → Литрес.
4. Работают ли **квиз** и **каталог** как помощники выбора.

## 2. Как создать цель (пошагово)

1. Откройте счётчик **110711984**.
2. **Настройка → Цели → Добавить цель**.
3. Тип: **JavaScript-событие**.
4. **Идентификатор цели** — **точно** как в таблице ниже (латиница, без пробелов, регистр важен).
5. Название (для себя) — на русском, как в колонке «Название в кабинете».
6. Условие: **совпадает** с идентификатором (одно условие, не «содержит»).
7. Цель-деньги: **необязательно**. Если включите «ценность», можно поставить условную ценность:
   - `litres` — 300–500 ₽ (оценка «клика к покупке», не чек);
   - `excerpt_download` — 50 ₽;
   - остальные — 0 или не задавать.
8. Сохранить.

Повторить для **всех приоритетных** целей из §3.

> Имя в коде: `reachGoal('litres', { book: 'reset', ... })`  
> Идентификатор в кабинете: **`litres`** (не `Litres`, не `click_litres`).

После одиночных целей: **Цели → Добавить → Составная цель** (или «многошаговая», если доступна в интерфейсе).

### Воронка «К качественной покупке»

| Шаг | Цель | Смысл |
|-----|------|--------|
| 1 | `book_view` | Открыл карточку |
| 2 | `excerpt_open` **или** `excerpt_download` | Посмотрел текст (если интерфейс позволяет «любую из» — лучше; иначе две воронки) |
| 3 | `litres` | Клик в магазин |

Если составная цель только «строго по цепочке в одном визите» — ок: так вы меряете **осознанный** путь, а не случайный клик с home.

## 5. Как смотреть отчёты (чтобы улучшать продажи)

### 5.1. Еженедельный ритуал (15 минут)

Период: **7 или 14 дней**, без «сегодня», с фильтром своих IP.

1. **Отчёты → Конверсии**  
   - `litres` / визиты = **конверсия в клик покупки** (ориентир на старте 1–5% от визитов; с карточки книги — выше).  
   - `excerpt_*` / `book_view` = **доля «сначала почитали»**.

2. **Конверсии → цель `litres` → группировка по параметру `book`**  
   (или отчёт «Параметры» / «Содержимое» — как в текущем UI).  
   **Вывод:** топ книг по кликам → усиливать на home (hero, doors, квиз, sticky).  
   Книги с `book_view` без `litres` → править CTA/цену/обещание на карточке.

3. **Воронка**  
   Где самый большой % отвала — туда UX/тексты:
   - home → book_view: слабый вход в каталог/doors/квиз;
   - book_view → excerpt: не видят «отрывок» или не доверяют;
   - excerpt → litres: текст не «закрывает», или CTA слабый.

4. **Источники** + цель `litres`  
   Откуда приходят **платящие по намерению** (direct / search / social).  
   Для постов всегда UTM:  
   `https://polgrek.site/knigi/reset/?utm_source=telegram&utm_medium=social&utm_campaign=reset_launch`

### 5.2. Что считать «качеством», а не «количеством»

| Хороший сигнал | Плохой сигнал |
|----------------|---------------|
| Высокий `excerpt` + затем `litres` | Много `litres` с home без `book_view` / excerpt (клики «наугад», мало дочитают) |
| `book_quiz_complete` → `litres` с той же книгой | Квиз есть, `litres` ≈ 0 |
| 2–3 книги дают 70% `litres` | Клики размазаны по 13 книгам без лидеров |
| `email_capture` / `telegram` растут | Только разовые прямые заходы, 0 return |

**Важно:** `litres` = **клик**, не оплата. Реальные продажи — кабинет Литрес / AdvCake. Сверяйте раз в месяц: клики Метрики vs заказы партнёрки.

### 5.3. Связка с партнёркой AdvCake

На сайте партнёрский URL подставляется при клике (`data-aff`).  
В Метрике цель `litres` + `book=slug`.  
В AdvCake — те же `sub1` / slug.  
Раз в 2 недели: топ slug в Метрике vs топ продаж в AdvCake — нет ли «кликают, но не покупают».

## 6. Проверка, что цели работают

1. Откройте сайт в режиме инкогнито (не свой IP, если отфильтрован).
2. **Подождите ~8–10 секунд** после полной загрузки (счётчик грузится с задержкой для скорости).
3. Откройте карточку книги → в «Онлайн» / через 5–15 мин цель `book_view`.
4. Клик «Отрывок» → `excerpt_open`.
5. Клик «Купить на Литрес» → `litres`.
6. Пройдите квиз до конца → `book_quiz_complete`.

Расширение [«Яндекс Метрика»](https://chrome.google.com/webstore) или вкладка Network: запросы к `mc.yandex.ru` с `goal=...`.

Если цели не появляются:

- опечатка в идентификаторе в кабинете;
- Adblock режет `mc.yandex.ru`;
- ушли со страницы **раньше**, чем подгрузился tag (очередь есть, но при мгновенном close может потеряться);
- цель создана как «URL», а не «JavaScript-событие».
